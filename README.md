
# CarNer Turn

A Turn Based Endless Runner Car Game 🚗
(for mobile/PC/Web)

## Controls 🎮

Touch Drag Left/Right - Change Direction
A/D - Change Direction

## Features 🛠️
💠 Car Change Every Time

💠 Procedurally Generated Paths

💠 Score Count

💠 UI

💠 10+ Different Vehicles
